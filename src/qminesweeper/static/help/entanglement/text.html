Entanglement counter

The counter with the two linked rings, measured in bits. For every cell it asks how entangled that cell is with the whole rest of the board, and adds the answers up.

A single Bell pair adds 2 bits: 1 for each of its two cells. Cells that are not entangled add 0, even when it is still uncertain whether they hide a mine. So this counter tells you how much entanglement is on the board, not where it is.

To find out where it is, use the entanglement probe and select an area. Selecting both cells of a Bell pair gives 0, because the pair is entangled with each other and with nothing outside, while this counter still reads 2.
