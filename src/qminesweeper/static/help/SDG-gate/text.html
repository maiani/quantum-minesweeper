S† gate

The SDG button applies S† — the S gate run backwards. Like S, it changes no number on the board.

$$ |+\rangle \to |-i\rangle \qquad |-\rangle \to |i\rangle $$

Apply S and then S† and the cell is exactly as it was. It sends $|i\rangle$ back to $|+\rangle$.

Formally, a 90$^\circ$ rotation about the "z-axis", in the opposite direction to S.
