CZ gate

If the control cell holds a mine, apply Z to the target; if it does not, leave the target alone.

Like the Z gate it is built from, CZ changes no mine probability anywhere on the board — and yet it entangles. Put two cells in an even superposition, apply CZ, and they come out entangled with every clue on the board unchanged. Only the linked-rings counter moves, from 0 to 2 bits.

That is worth sitting with: the numbers you can see do not tell you everything about the board.

CZ does not care which cell you click first — control and target are interchangeable, unlike CX. It undoes itself as well.
